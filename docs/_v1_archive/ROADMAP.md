# Master Mentor — Basic to Expert Preparation Roadmap

This is the actual curriculum the user follows. It is deliberately sequenced and designed for ~10 hours/week.

## Level 0 — Baseline

**Goal:** measure the starting point.

- DSA: 7 unseen problems
- CS: baseline questionnaire
- System design: URL Shortener
- Behavioral: 2 recorded answers
- Coding: one timed implementation
- Record time, hints, mistakes and confidence

**Exit:** baseline report created.

### Mastery standard

Easy: usually <=15 minutes.

Medium: usually <=25–35 minutes.

Hard: meaningful progress + correct strategy discussion.

The system values pattern recognition, correctness, explanation and timed performance more than raw problem count.

## Level 9 — Final Simulation

Requirements before declaring ready:

- DSA >= 75
- CS >= 65
- System design >= 70
- coding/execution >= 70
- behavioral/communication >= 70
- recent 5-mock average >= 70
- zero critical gaps
- no critical overdue revisions
- 3 consecutive passing final simulations

These are product thresholds, not company hiring guarantees.
