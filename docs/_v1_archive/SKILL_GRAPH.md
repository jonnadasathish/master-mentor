# Master Mentor — Product Company Skill Graph

## Purpose

This is the canonical skill taxonomy used by the mentor.

Each skill should eventually become a database row with:
- `skill_id`
- `name`
- `parent_id`
- `category`
- `target_level`
- `importance`
- `prerequisites`
- `evidence_types`
